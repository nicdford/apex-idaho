How it works

Up and running in three steps

Pitwall is self-hosted and open source. Install once and your whole team gets instant access to your event data.

1

Install the WordPress plugin

Drop the Pitwall plugin into your WordPress site. Generate an API key in the settings page and copy it — that's your secure bridge to your event data.

2

Deploy the Discord bot

Run the Pitwall bot on any server or cloud platform using Docker. Point it at your WordPress site with your API key and Anthropic API key, and invite it to your Discord.

3

Ask anything in Discord

Start a conversation in any authorized channel. Ask about ticket counts, search for attendees, check capacity — Pitwall understands natural language and responds instantly.

Features

Everything your event team needs

Pitwall handles the most common event operations questions so your team can stop digging through dashboards.

💬

Natural language queries

Ask questions the way you'd ask a colleague. No commands to memorize, no dashboards to navigate. Pitwall understands context and gives clear, formatted answers.

🔍

Attendee search

Search across all your events by name or email in seconds. Filter by ticket type or order status to pinpoint exactly who you're looking for.

🎫

Live ticket capacity

Check sold, pending, and available ticket counts for any event or ticket tier in real time — pulled directly from The Events Calendar and WooCommerce.

📌

Channel-pinned events

Pin a specific event to a Discord channel with /setevent. Every question in that channel defaults to that event — perfect for event-specific ops channels.

🧠

Conversation memory

Pitwall remembers your conversation context within a session. Ask follow-up questions naturally — no need to repeat yourself every message.

🔐

Secure by default

API key authentication between the bot and your WordPress site. The REST API is read-only — Pitwall can never modify your data. Channel-level access controls keep things organized.

Requirements

What you need to get started

Pitwall is a thin layer on top of tools you likely already use. Self-hosted, open source, and free to run (apart from API usage costs).

🌐

WordPress site

WordPress 6.0 or later, running The Events Calendar plugin. WooCommerce or Tickets Commerce supported for ticketing.

Discord bot token

A Discord application and bot token from the Discord Developer Portal. Pitwall handles slash command registration automatically on startup.

🤖

Anthropic API key

An API key from Anthropic to power the Claude AI model. Usage costs are typically very low for event operations workloads.

🐳

A place to run the bot

Any server, VPS, or cloud platform that can run Docker containers. The repo includes a Fly.io config for one-command deploys.
